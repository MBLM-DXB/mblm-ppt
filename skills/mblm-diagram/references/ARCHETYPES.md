## 2. Inbound Marketing Methodology

**Layout:** Horizontal 5-step flow with connector arrows  
**SVG fallback:** `assets/mblm/diagrams/inbound_marketing_5_step.svg`  
**Canvas hint:** 5 steps × ~220px = ~1100px wide, ~280px tall (or full 1280×720 slide with title)

| Step | Label | Icon Cluster | Detail |
|---|---|---|---|
| 1 | ATTRACT | `megaphone` + `line-chart` | Awareness, reach, content broadcast |
| 2 | CONVERT | `person` + `document` + `speech-bubble` | Lead capture, forms, landing pages |
| 3 | NURTURE | `email-envelope` + `person-group-3` | Email sequences, segmentation |
| 4 | CLOSE | `bar-chart` + `circled-R` | CRM, proposals, brand-qualified leads |
| 5 | DELIGHT | `gear` + `magnifier` + `person-group-3` | Optimise, retain, measure |

Connectors: thin horizontal line + arrowhead between each step, y-centered on icon clusters.  
Labels: uppercase sans-serif small-caps, below each icon cluster.

## 4. Generic Process Flow (Fallback)

**Layout:** Horizontal N-step flow (3–5 steps)  
**SVG fallback:** `assets/mblm/diagrams/generic_process_5_step.svg` (placeholders `{{STEP_1}}` … `{{STEP_5}}`)

Map each phase to the closest icon cluster from the library. If a concept
has no matching icon, use `document` as the neutral fallback. Never invent
geometry not in the library.
