# Icon Library (Prompt Vocabulary)

Use these exact descriptions when specifying icons in image prompts.

| Icon | Visual Description |
|---|---|
| `circled-R` | Double-ring circle (thin outer, thin inner), R as vector strokes: vertical bar left, two arc bumps right, diagonal leg bottom-right |
| `magnifier` | Circle lens, short diagonal handle bottom-right |
| `document` | Page outline, folded top-right corner, 2–3 horizontal ruled lines inside |
| `document-rmark` | Page outline, folded corner, circled-R centered on face |
| `document-image` | Page outline, folded corner, small landscape image placeholder rectangle inside |
| `document-Ai` | Page outline, folded corner, "Ai" letterform strokes on face |
| `open-book` | Two pages, center spine, ruled lines on each page |
| `open-book-rmark` | Two pages, center spine, circled-R on right page |
| `monitor` | Wide screen rect, inner bezel rect, content lines on screen, short neck, wide base |
| `monitor-rmark` | Monitor with circled-R centered on screen |
| `monitor-www` | Monitor with "www." text/wavy lines on screen, tablet beside it |
| `monitor-gear` | Monitor with gear symbol on screen |
| `monitor-code` | Monitor with `< >` bracket symbols on screen |
| `monitor-chart` | Monitor with line chart visible on screen, on stand legs |
| `laptop` | Open screen rect with content lines, flat keyboard base rect |
| `tablet` | Tall rounded rect, inner screen rect, small home button circle bottom |
| `phone` | Narrow tall rounded rect, inner screen, home button |
| `person` | Circle head, vertical torso, angled arm polyline, two splayed leg lines |
| `person-group-3` | Three person figures side by side, outer two smaller |
| `person-group-5` | Five person figures side by side, outer ones progressively smaller |
| `speech-bubble` | Rounded rect, downward tail bottom-left, 2 content lines inside |
| `megaphone` | Tapered horn widening right, rect mouthpiece left, 2 sound wave arcs right |
| `gear` | Center circle, inner hole, 8 tooth stubs at cardinal + diagonal positions |
| `camera` | Rounded rect body, circle lens, inner lens circle, viewfinder bump top-left, shutter button top-right |
| `video-frame` | Rectangle with film sprocket strips left and right sides, play triangle inside |
| `image-frame` | Rectangle with small mountain/landscape icon inside (photo placeholder) |
| `bar-chart` | X+Y axes, 3 ascending outlined rect bars |
| `line-chart` | X+Y axes, upward-trending polyline |
| `trifold-brochure` | Three vertical panels fanned slightly, each with ruled lines |
| `presentation-screen` | Wide landscape rect on two stand legs, bar chart or content inside |
| `grid-layout` | Outer rect, header row, 2-column grid, footer row |
| `design-system-grid` | Outer frame, 3 swatch squares top (one black filled, one X, one A), type lines below |
| `type-specimen` | Page outline, large ABCDE letterform lines, smaller sub-lines |
| `package-box` | Rect body, flat lid rect, cross ribbon (vertical + horizontal lines) |
| `email-envelope` | Rectangle, V-fold diagonal lines from top corners meeting center |
| `server-stack` | 3 stacked horizontal rounded rects, small circle indicator on each |
| `social-facebook` | Solid black circle, white "f" inside |
| `social-x` | Solid black circle, white "X" inside |
| `social-linkedin` | Solid black circle, white "in" inside |
| `bracket-divider` | Vertical bar with two short horizontal bracket arms, representing structured content |
| `identity-hierarchy` | One large circled-R + two medium circled-R marks + one small circled-R, arranged in hierarchy |
| `blueprint-docs` | Two stacked grid-layout documents, slightly offset |
| `connector-arrow` | Horizontal line + small arrowhead pointing right |
