# MBLM Illustration — Palette lock

## Foundation (pick one background per image)

| Name | Typical use | Notes |
|---|---|---|
| Stark white `#FFFFFF` | Default content-slide figure | Best for centered metaphors with padding |
| Paper gray | Soft editorial / print feel | Still one accent only |
| Deep black / charcoal | High-drama section or cover-adjacent | Accent must remain readable; white linework OK |

## Accents — exactly ONE per image

| CLI key | Name | Hex |
|---|---|---|
| `yellow` | Yellow | `#FFF200` |
| `orange` | Orange | `#FFBA00` |
| `magenta` | Magenta | `#EC008C` |
| `violet` | Violet | `#9700DC` |
| `blue` | Blue | `#006AF1` |
| `cyan` | Cyan | `#00AEFF` |
| `green` | Green | `#00D300` |

## Never-mix rule

* Do **not** combine two accents in one illustration.
* Do **not** recolor monoline **diagrams** with these accents (diagrams stay black/white — see `skills/mblm-diagram`).
* Kit icons and chrome may use brand tokens separately; the **generated illustration PNG** itself remains one-accent.
* Yellow (`#FFF200`) is allowed as fill/texture in illustrations; still never use yellow as **divider lines** on slides (deck freeze).
