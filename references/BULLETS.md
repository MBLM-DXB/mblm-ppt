# MBLM Bullets (HARD — v4.1.1 / 2026-09-10)

## Canonical bullet

| Property | Rule |
|---|---|
| Shape | **Round solid circle** |
| Color | **Black** (`#000000`) |
| Diameter | ≈ **80% of the adjacent body text size** (e.g. 20px text → ~16px diameter; 16px text → ~12.8px diameter) |
| Indent | Clear gap bullet → text; hanging indent so wrap lines align under text, not under bullet |
| Weight | Circles are filled solids — not outlined rings, not triangles, not dashes |

## User override (overrides R2 screenshots)

Some R2 consulting-template screenshots use:
- light-blue **triangles**
- blue circles with white checkmarks
- blue dashes / dots

**Agents must NOT copy those.** Always use **round black circles** per this file.

## Allowed non-bullet markers (not list bullets)

| Marker | When |
|---|---|
| Numbered black circles (01, 02…) | Agenda / Content TOC (Pattern J — r2_12) |
| Blue process nodes / chevrons | Process / timeline diagrams |
| Letter circles (A–G) linking to matrices | Risk / assessment layouts |
| White icons in black/blue circles | Pillar / deliverable icon headers |

These are **diagram markers**, not paragraph list bullets. Paragraph lists still use round black circles.
