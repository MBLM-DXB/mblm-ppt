# MBLM Imagery & Brand Intimacy

## Photography styles (from brand-kit screenshot)

| Style | Description | Deck use |
|---|---|---|
| **In Motion** | Long-exposure light streaks; energy/speed | Section openers, digital/tech stories |
| **Silhouettes** | Human figures against glowing **brand gradients** | Emotional / intimacy narratives |
| **People** | Portraits, dramatic natural light, high contrast | Case studies, leadership, culture |
| **Close-ups** | Extreme detail (hand, eye, texture) | Intimacy, craft, sensory stories |

For **AI film stills** matching cool blue-teal + one warm source, use nested skill
`skills/mblm-cinematic/` (Cinematic Human Light). See [`IMAGES_GEN.md`](IMAGES_GEN.md).

Avoid generic stock handshakes and cliché corporate office tropes unless the user supplies them.

For abstract strategy / capability metaphors, use **`mblm-illustration`** — textured landscapes, tiny faceless figures, exactly one accent. See [`IMAGES_GEN.md`](IMAGES_GEN.md) and `skills/mblm-illustration/`.
