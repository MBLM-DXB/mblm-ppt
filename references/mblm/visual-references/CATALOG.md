# Visual References Catalog

Source mirror: `${MBLM_MASTER_ROOT}/skill/_spec_screens_ascii/` (55 PNGs + INDEX.txt).
Original folder (NNBSP filenames): `${MBLM_MASTER_ROOT}/MBLM slides and other specs/`.

**Authority**: These screenshots + user hard rules (see `../LINE_RULES.md`, `../TYPOGRAPHY.md`) drive design. Do not invent McKinsey-style decks.

**User overrides** (even if a screenshot shows otherwise) — see also **v3.0.0** locks in `SKILL.md` and R2 catalog [`CATALOG_R2.md`](CATALOG_R2.md):
- Yellow (`#FFF200` or other yellows) **forbidden** as vertical/horizontal divider or accent **lines**.
- Lines sitting above square/card shapes must be **blue family only** (`#002A60` / `#006AF1` / `#00AEFF` / `#0068EB`). Never rainbow/yellow/magenta/green card-header bars.
- **No kickers**; title ≤**40pt** Light, logo-aligned, **normal kerning**; Supertext stroke **1.25pt** edge-to-edge.
- Margins ~**62** L/R, ~**45** bottom; bullets = round **black** circles; no tagline/bottom wordmark with logo; white-only on black fills; gradients mainly for section dividers; no line-box stacks.
- Agenda gold standard: **r2_12** + **r2_40** in CATALOG_R2.
