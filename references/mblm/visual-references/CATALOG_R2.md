# Visual References Catalog — R2 (Consulting proposal examples)

**Version**: skill v3.0.0 (2026-09-10)
**ASCII mirror**: `${MBLM_MASTER_ROOT}/skill/_examples_r2_ascii/` (40 PNGs + INDEX.txt)
**Original folder**: `${MBLM_MASTER_ROOT}/more examples r2/`

**Authority**: These examples + user v3 hard rules (`SKILL.md` freeze, `MARGINS.md`, `BULLETS.md`, `TYPOGRAPHY.md`, `LINE_RULES.md`, `LOGOS.md`) drive consulting-content layouts. Adapt patterns; do **not** copy deprecated markers (blue triangles, kickers, taglines under logo).

**User overrides** (even if a screenshot shows otherwise):
- No kickers / eyebrows above titles (zero tolerance)
- Title max **40pt** Light; title top aligned to logo top; **normal kerning**
- Margins: sides ~**62px** (56–67); bottom ~**45px** (was ~80–96 / ~64)
- Bullets = **round black circles** (~50% text size) — not blue triangles/checks
- No tagline when logo present; no bottom MBLM wordmark if logo already on slide
- On black fills: **white text only** — no yellow text, no blue accent lines on black
- Gradients mainly for **section dividers** — not full-bleed on ordinary content slides
- No line-box stacks (prefer solid fills + paragraph blocks)
- Supertext stroke **1.25pt**, edge-to-edge when used
- Agenda gold standard: **r2_12** (Content numbered TOC) + **r2_40** (section agenda list)

## Anti-patterns in R2 (do not copy)

- Kickers / eyebrows above titles (r2_38 labels)
- Blue triangle / checkmark / dash bullets (r2_02, r2_03, r2_08)
- Tagline under logo or bottom MBLM wordmark when logo present (none of the good content slides use these — keep it that way)
- Yellow text on black; blue accent lines on black boxes
- Full-bleed gradients on ordinary white content slides
- Stacks of stroked empty rectangles as UI
- Expanded title tracking / kerning
